🧠 MEMORY: **CRITICAL LESSON** for future Cloudflare Pages Function work: env vars are passed via `context.env` inside the handler — NOT as a module-scope global. The original commit 5c05943e referenced `env.RESEND_API_KEY` at module-init time, which would crash with `ReferenceError: env is not defined` on first request. The fix pattern: read env-derived config per-request via `context.env` and thread values through helper functions as parameters (or read in the handler and pass to helpers).
